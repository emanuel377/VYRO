# Inventario y derechos de recursos visuales

Consulta: 2026-10-21. Los 32 archivos JPG de `public/assets/` se derivan de **siete imágenes base generadas para este proyecto con ImageGen** y una edición adicional del abrigo conceptual. Las imágenes base comprenden cinco escenas hero y dos planchas de 12 recortes cada una para menú y catálogo. Se convirtieron o recortaron localmente sin incorporar archivos de Pinterest, bancos de imágenes ni marcas ajenas. Las capturas que entregó el usuario se usaron para orientar composición y estilo, no como recursos publicados.
